# ApnaMensWear — Full-Stack E-Commerce Platform

A production-oriented full-stack e-commerce application built with the **MERN stack**, with authentication, payments, cloud storage, caching, shipping integration, and role-based access control.

**Integrations**

* Razorpay — Payments
* Cloudinary — Image Storage
* Shiprocket — Shipping & Delivery



## 🚀 Tech Stack

**Frontend**

* React.js
* Vite
* JavaScript
* CSS Modules
* React Router
* Axios

**Backend**

* Node.js
* Express.js
* REST API
* JWT Authentication
* Role-Based Access Control

**Database & Caching**

* MongoDB
* Mongoose
* Redis

**Deployment**

* Vercel
* Render
